# Memory Game

Игра на память: нужно найти все парные карточки за минимальное число ходов.

## Описание

**Memory Game** - это классическая игра на тренировку памяти. На поле 4×4 лежат 16 карточек рубашкой вверх, 8 пар одинаковых карточек. Игрок открывает по две карточки: если иконки совпали, пара остаётся открытой, если нет - обе закрываются через 700 мс. Необходимо открыть все пары за минимальное количество ходов.

Результаты сохраняются в Local Storage и попадают в таблицу лидеров: 10 лучших игр с указанием числа ходов и даты.

## Функциональность

- Игровое поле 4×4, 16 карточек, 8 пар.
- Случайное перемешивание карточек при каждой новой игре.
- Счётчики ходов и найденных пар.
- Модальное окно победы с итоговым числом ходов.
- Таблица лидеров.
- Сохранение результатов и доступ после перезагрузки страницы.

## Запуск локально

Склонируйте репозиторий:

```bash
git clone https://github.com/Ulya10/memory-game.git
cd memory-game
```
### Способ 1. Открыть напрямую в браузере

Откройте файл *index.html* двойным кликом. Игра запустится сразу, сторонних зависимостей нет.

### Способ 2. Live Server (VS Code)

1. Установите расширение **Live Server** в VS Code.
2. Откройте папку проекта в редакторе.
3. Правый клик по *index.html* → **Open with Live Server**.

Браузер откроется по адресу вида `http://127.0.0.1:5500`.
